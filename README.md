# 🌐 Shreya Yadav – Personal Portfolio Website

This is my personal portfolio website that showcases who I am, what I do, and how I build things on the web. It highlights my skills, experience, and contact information in a visually appealing, responsive layout.

---

## ✨ Features

- 🧑‍💼 About Me section with summary and specialties
- 🛠️ Skills section highlighting tools and technologies I work with
- 📂 Projects section (live GitHub and app links)
- 📄 Resume download button
- 📬 Contact form (via email or social media)
- 🔄 Fully responsive and mobile-friendly

---

## 🧰 Tech Stack

- **HTML5, CSS3, JavaScript**
- **Tailwind CSS** for utility-first design
- **React Icons / Material UI** for icons
- **PHP + MySQL** for form handling (if backend is enabled)
- **VS Code**, GitHub, Netlify (for deployment)
